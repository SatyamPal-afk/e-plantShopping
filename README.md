# e-plantShopping

## Paradise Nursery Shopping Application

**e-plantShopping** is a React-based shopping cart application developed as the final project for the Developing Front-End Apps with React course.

The application represents an online plant shop called **Paradise Nursery**, where users can browse different categories of houseplants, add plants to their cart, update quantities, remove items, and view the total purchase cost.

## Features

- Landing page with a **Get Started** button
- Navigation between the landing, product listing, and shopping cart pages
- Plants organized into categories such as Aromatic Plants and Medicinal Plants
- Plant cards displaying images, names, descriptions, and prices
- Add plants to the shopping cart
- Live cart quantity displayed in the navigation bar
- Increase or decrease plant quantities
- Remove plants from the cart
- Dynamically calculate individual item totals and the overall cart total
- Continue Shopping and Checkout buttons

## Technologies Used

- React
- JavaScript
- JSX
- Redux Toolkit
- React Redux
- Vite
- HTML
- CSS
